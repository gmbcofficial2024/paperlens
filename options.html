Settings

Translate and summarize papers and articles on the page you are reading.

Start with one API key

Choose Google Gemini, enter your own API key, then click Save Settings. A blank Gemini summary key reuses that saved key. No local CLI is needed.

Open a paper or article and press Alt+T to translate or Alt+S to summarize. Requests use your provider account and may incur API charges. Only content loaded on the page can be read.
